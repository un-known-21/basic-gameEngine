# Basic Game Engine
- 2d pixel art based game Engine
- Runs on browser via Html

FUNCTIONALITY 
- Use Arrow-up, down, left, right for Mobility of character.
- Getting close to monster(slime) for about 4x4 pixels the monster(slime) will follow the character and attack it.
- Press 'Spacebar' for attack when near the character is near the monster.
- When switch to next map on left side the Store will be visible and then enter inside the store by getting near the door.
- Get near the shopkeeper and press 'Enter' to interact.
  Use 'arrow-up' and 'arrow-down' for up and down movement of cursor.
  Only weapon is available and into which only iron sword has it's asset .. others don't.
  Use 'Enter' keyword for Enter and item purchase.
- Press "I" keyword to open/close Inventory.
- Press "C" keyword for Character stats.
